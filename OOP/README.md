# Лабораторна робота №1

**Тема:** Знайомство із середовищем розробки та складання модульних проєктів програм
**Дисципліна:** Об'єктно-орієнтоване програмування
**Мова:** Python 3 + tkinter (кросплатформно: Windows, macOS, Linux)

## Варіант

Номер у журналі Ж = 14:

- **B1** = 14 mod 4 = **2**: два діалогові вікна з кнопками [Далі >], [< Назад], [Так], [Відміна]
- **B2** = (14 + 1) mod 4 = **3**: діалогове вікно зі списком (Listbox) груп та кнопками [Так], [Відміна]

## Що робить програма

У головному вікні є два пункти: **«робота 1»** та **«робота 2»** (кнопки у верхній частині вікна).

**робота 1.** Відкривається перше діалогове вікно з кнопками [Далі >] та [Відміна]. Після [Далі >] воно закривається і з'являється друге вікно з кнопками [< Назад], [Так] та [Відміна]. [< Назад] повертає до першого вікна, [Так] показує результат у головному вікні.

**робота 2.** Відкривається діалог зі списком груп. Після вибору рядка та натискання [Так] текст вибраної групи відображається в головному вікні.

## Структура проєкту

```
Lab1/
├── main.py      # головне вікно, пункти «робота 1» / «робота 2», mainloop
├── module1.py   # діалог 1 для B1 (кнопки [Далі >], [Відміна])
├── module2.py   # діалог 2 для B1 (кнопки [< Назад], [Так], [Відміна])
├── module3.py   # діалог для B2 (список груп)
└── utils.py     # спільний код: make_dialog, add_buttons
```

## Основні принципи

- Кожне діалогове вікно знаходиться в окремому незалежному модулі.
- Модулі не імпортують один одного, лише спільний `utils.py`.
- Класи діалогів приватні (назва з `_`), назовні доступна лише функція `open_dialog`
- Переходи між вікнами керуються з `main.py`: діалоги отримують функції зворотного виклику (callback) і викликають їх за потреби.
- При виведенні наступного діалогу попереднє вікно закривається автоматично.
